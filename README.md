# ShieldCore — учебный прототип антивирусного сканера

**Статус:** MVP для экспериментов, не коммерческий и не полноценный антивирус. Это не замена Microsoft Defender или другому установленному защитному ПО. Не отключайте системную защиту. В Windows есть опциональная передача проверки встроенному Microsoft Defender; собственного kernel-драйвера нет.

## Требования
Python 3.9+; только стандартная библиотека. Работает на Windows, macOS и Linux как ручной сканер.

## Запуск приложения с интерфейсом
На Windows установите Python 3.9+ с включённым компонентом Tcl/Tk, затем дважды нажмите `Запустить_ShieldCore.bat` или выполните `python shieldcore_gui.py`. Для безопасной локальной самопроверки запустите `Локальная_проверка_ShieldCore.bat`: он запускает тесты/проверку БД, ничего не загружает в сеть и не сканирует личные папки; отчёт сохраняется на рабочем столе. В окне можно выбрать файл/папку, запустить или отменить сканирование, видеть прогресс по мере прохода, просмотреть журнал, добавить SHA-256 сигнатуру, задать интервал мониторинга (2–60 секунд) и управлять исключениями папок.

Мониторинг делает начальный снимок текущих файлов, а затем проверяет новые и изменённые; он не сканирует начальное содержимое сам по себе и не является защитой ОС в реальном времени. Держите Microsoft Defender включённым.

## CLI
В папке проекта:

```bash
python shieldcore.py scan "путь/к/папке"
python shieldcore.py report
```

Опциональная изоляция обнаруженного (файл перемещается, не удаляется; хеш проверяется повторно):

```bash
python shieldcore.py scan "путь/к/папке" --quarantine
python shieldcore.py report
python shieldcore.py restore ID_ИЗ_ОТЧЕТА
```

Для восстановления в другой путь: `python shieldcore.py restore ID --to "путь/к/файлу"`. Перезапись существующего файла запрещена; перед восстановлением снова проверяется хеш.

Импортировать проверенный вручную JSON-feed с SHA-256 индикаторами и посмотреть состояние базы:

```bash
python shieldcore.py import-db signature-feed.example.json
python shieldcore.py db-info
```

Формат и ограничения feed описаны в `DATABASE.md`. Пример содержит только SHA-256 безвредного тестового маркера EICAR, не реальные образцы вредоносного ПО.

Добавить SHA-256 индикатор выбранного файла локально:

```bash
python shieldcore.py add-hash подозрительный_файл.bin --name "имя сигнатуры"
```

Хеши сигнатур берите только из проверенного источника. Встроена только безвредная тестовая сигнатура EICAR; эвристика скриптов — лишь грубый индикатор и может ошибаться.

## Компоненты и данные
- `shieldcore.py` — CLI, обход файлов, вычисление SHA-256, простая эвристика, изоляция.
- SQLite и карантин хранятся в пользовательском каталоге данных: Windows `%LOCALAPPDATA%\\ShieldCore`; Linux/macOS `$XDG_DATA_HOME/shieldcore` или `~/.local/share/shieldcore`.
- Таблицы: `signatures` (сигнатуры), `scans` (запуски), `findings` (находки), `quarantine` (метаданные изоляции), `events` (аудит).
- Подозрительный файл перемещается в `quarantine/` под случайным именем `.bin`; хеш перепроверяется перед и после перемещения.
- Автоматические тесты: `python -m unittest discover -s tests -v`. 

## Ограничения и безопасность
Нет драйвера, самозащиты, облачной репутации, обновления сигнатур, анализа памяти/архивов, распаковки, сетевого экрана, защиты при открытии/запуске и подтверждённой базы угроз. Сканер ограничивает файлы 250 MiB, поэтому более крупные файлы пропускаются. Эвристика может давать ложные срабатывания. Перед использованием `--quarantine` убедитесь, что понимаете восстановление и делаете резервные копии. Не используйте на важных данных без тестирования. Для реальной защиты оставьте включённым Windows Defender.
